# Self-Documentary

A minimal Markdown-driven personal archive inspired by encyclopedia interfaces.

## Structure

- `PROFILE.md` — the project owner's personal profile and self-documentary.
- `index.json` — the index used by the site to discover and list Markdown pages.
- `index.html`, `style.css`, `script.js` — the site interface and Markdown renderer.
- `AI_DISCLAIMER.md` — disclosure of AI use in software development.
- `log.md` — development history.
- `LICENSE` — MIT License.

## PROFILE.md

`PROFILE.md` is where the project owner writes about himself.

Its personal and self-documentary content is written entirely by the owner. It is not generated by AI. The file can be expanded freely with ordinary Markdown headings, paragraphs, lists, links, tables, and other supported Markdown syntax.

## Add more Markdown pages

1. Create a Markdown file in the repository.
2. Add it to `index.json`.
3. Commit and push.

Example:

```json
{
  "slug": "journal",
  "title": "Journal",
  "file": "JOURNAL.md",
  "description": "Personal journal."
}
```

The site reads `index.json`, loads the selected Markdown file, and builds page navigation automatically.

## Run

Serve the repository over HTTP/HTTPS using GitHub Pages or any static web server. Direct `file://` loading is not supported because Markdown files are fetched in the browser.
