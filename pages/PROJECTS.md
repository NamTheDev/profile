# Projects

Nam (also known as namchill235 and NamTheDev) works on projects in music, photography, audiovisual media and software development. The following overview includes ongoing creative work, software applications and earlier projects retained for archival purposes.

## Creative works

### Ashes

Ashes is an audiovisual project by Nam and Unecap documenting liminal spaces and exploring realistic horror. Its footage is recorded in real locations by real people. The project states: *"We officially do NOT tolerate AI use in our content."*

Videos are published on the [Ashes YouTube channel (@smertelnyyfootages)](https://www.youtube.com/@smertelnyyfootages).

### Music

Nam's compositions explore experimental music and fusion. Rather than working within a single genre, he draws on music and other experiences that have influenced him. He describes his approach as follows:

> I experiment with music. My music isn't defined, it's a mixture of a lot of things I have consumed, experienced, and as well as putting out from within.

His recordings are available on [Bandcamp](https://namchill235.bandcamp.com) and [YouTube (@namrhythmical)](https://www.youtube.com/@namrhythmical).

### Photography

Nam's photography, artwork and other visual works are published on [Cara](https://cara.app/namchill235/portfolio) and the [Nam Rhythmical Facebook page](https://www.facebook.com/namrythmical).

## Software

### Profile

[Profile](https://github.com/NamTheDev/profile) is a personal documentation website inspired by Wikipedia. It presents Markdown documents in an article-based interface with page navigation and a table of contents. Written in HTML, CSS and JavaScript, the site uses a service worker to cache local resources for offline use.

### MeditorD

[MeditorD](https://github.com/NamTheDev/MeditorD) is a self-hosted Markdown editor and folder-based media archive. Its interface draws on nostalgic software design. The application is developed using Bun, TypeScript and SQLite.

### MCP-Server

[MCP-Server](https://github.com/NamTheDev/MCP-Server) is an experimental implementation of the Model Context Protocol (MCP) over HTTP. Written in TypeScript using Bun, it provides tools and integrations for AI assistants, including modules for reminders, knowledge, agents and Discord. Its repository documents the use of AI assistance during development.

### keep

[keep](https://namthedev.github.io/keep/) is a local-first web application for organizing personal notes. It supports checklists, labels, reminders, archiving and JSON backups. Notes and preferences are stored in the browser without an account or cloud synchronization.

The application shares a compact, Catppuccin-based Bootstrap interface with clipboard. Its [source code](https://github.com/NamTheDev/keep) is available on GitHub.

### clipboard

[clipboard](https://namthedev.github.io/clipboard/) is a web application for temporarily sharing text between devices. Users create or join vaults using six-character identifiers. Guests can read and copy shared items, while owners can manage their contents. Vaults expire after either 24 hours or seven days.

The frontend is hosted on GitHub Pages and communicates with a separate Node.js and SQLite API. The [source code](https://github.com/NamTheDev/clipboard) is available on GitHub.

### util

[util](https://github.com/NamTheDev/util) is a repository of shared utilities, design assets and contribution standards. It contains the common Bootstrap configuration used by Profile, keep and clipboard, as well as documentation for repository formatting and development practices.

## Archived projects

### Green

[Green](https://github.com/NamTheDev/Green) was a Discord bot developed to manage the Minecraft and Discord servers of Unecraft, formerly known as NGCL (NamGreenCapLand). Development has ceased and its repository is retained as an archive.

### FEARLESS

[FEARLESS](https://github.com/NamTheDev/FEARLESS) was a Discord bot developed for internal automation and community management in Ruthless Fears, a community associated with the Roblox game The Strongest Battleground. The community has since disbanded and the bot is no longer maintained.

### FARTLESS

[FARTLESS](https://github.com/NamTheDev/FARTLESS) was a Discord bot with economy, loot, shop, inventory and receipt systems. Its functionality was subsequently incorporated into FEARLESS. Both repositories are archived.

### Flow

[Flow](https://github.com/NamTheDev/Flow) was an experimental development project using Bun and TypeScript. It is no longer maintained.
